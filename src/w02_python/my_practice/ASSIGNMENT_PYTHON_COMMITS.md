# Python 주제별 실습 정리

이번 실습에서는 Git 저장소의 Python 예제를 주제별로 확인하고 실행했다.

## 1. 리스트

**강의 의도**

- 여러 값을 순서대로 저장하고 `for` 문으로 반복하는 방법을 익히는 것이다.
- `append`, `pop`, `enumerate`로 리스트를 수정하고 순회하는 방법을 확인했다.

**C·C++과 비교 및 느낀 점**

- C의 배열은 크기를 미리 정해야 하지만 Python 리스트는 쉽게 늘리거나 줄일 수 있었다.
- C++의 `vector`와 비슷하지만 Python은 자료형 선언 없이 바로 사용할 수 있어 편했다. 대신 C·C++보다 속도와 메모리 사용량은 불리할 수 있다고 느꼈다.

## 2. 리스트 슬라이싱

**강의 의도**

- 필요한 구간만 `[start:end]`로 꺼내고, 복사와 참조의 차이를 이해하는 것이다.
- 같은 리스트를 가리키는 경우와 슬라이싱으로 새 리스트를 만든 경우를 비교했다.

**C·C++과 비교 및 느낀 점**

- C 배열은 원하는 구간을 따로 반복해서 복사해야 하지만 Python은 짧게 표현할 수 있었다.
- 편리하지만 슬라이싱은 새 리스트를 만들 수 있으므로 큰 자료에서는 메모리 사용을 생각해야 한다.

## 3. 딕셔너리

**강의 의도**

- 키와 값으로 자료를 저장하고 안전하게 조회하는 방법을 익히는 것이다.
- 없는 키는 `get()`이나 `in`으로 처리하고, `items()`로 키와 값을 함께 반복하는 방법을 확인했다.

**C·C++과 비교 및 느낀 점**

- C에는 기본 딕셔너리가 없어서 직접 구현해야 하지만 Python에서는 바로 사용할 수 있었다.
- C++의 `map`, `unordered_map`과 비슷하지만 Python은 문법이 간단하다. 반면 키 이름을 잘못 적어도 실행할 때 확인되는 점은 주의해야 한다.

## 4. 딕셔너리 활용

**강의 의도**

- 단어 수 세기처럼 딕셔너리를 빈도표와 그래프 형태로 활용하는 방법을 익히는 것이다.
- `defaultdict`, 정렬, 중첩 딕셔너리를 사용해 자료를 정리하는 방법을 보았다.

**C·C++과 비교 및 느낀 점**

- C에서는 빈도표를 배열이나 구조체로 직접 설계해야 해서 코드가 길어질 수 있다.
- Python은 자료를 빠르게 정리하기 좋았지만, 자료가 커질수록 어떤 자료구조가 적절한지 생각해야 한다.

## 5. 세트

**강의 의도**

- 중복을 제거하고 특정 값이 있는지 빠르게 확인하는 세트의 특징을 익히는 것이다.
- `add()`와 멤버십 검사, 정렬된 출력 방법을 확인했다.

**C·C++과 비교 및 느낀 점**

- C에는 세트가 기본으로 없고, C++에서는 `set`이나 `unordered_set`을 사용해야 한다.
- Python 세트는 바로 쓸 수 있어 편했지만 출력 순서가 항상 같지 않을 수 있으므로 결과를 보여 줄 때는 정렬이 필요했다.

## 6. 튜플

**강의 의도**

- 여러 값을 한 묶음으로 저장하고 언패킹하는 방법을 익히는 것이다.
- 튜플은 수정할 수 없고 리스트는 수정할 수 있다는 차이를 확인했다.

**C·C++과 비교 및 느낀 점**

- C에서는 구조체, C++에서는 `struct`나 `tuple`로 여러 값을 묶을 수 있다.
- Python 튜플은 만들고 풀어 쓰기가 간단해서 함수 결과를 여러 개 받을 때 편했다. 다만 수정이 필요하면 리스트로 바꿔야 한다.

## 7. 함수

**강의 의도**

- 함수를 정의하고 호출하며, 지역 변수와 전역 변수의 범위를 이해하는 것이다.
- 위치 인자, 키워드 인자, 여러 값 반환을 연습했다.

**C·C++과 비교 및 느낀 점**

- C·C++은 매개변수와 반환형을 미리 선언해야 하지만 Python은 작성이 더 간단했다.
- Python은 키워드 인자로 호출 의도를 잘 보여 줄 수 있는 장점이 있다. 대신 자료형 오류가 실행 중에 나타날 수 있다.

## 8. 클래스

**강의 의도**

- 클래스와 객체의 기본 구조, 생성자, 메서드, 상속을 이해하는 것이다.
- 같은 메서드를 가진 객체를 비슷하게 사용하는 덕 타이핑도 확인했다.

**C·C++과 비교 및 느낀 점**

- C는 구조체와 함수를 따로 관리하는 경우가 많고, C++은 클래스 기능이 더 엄격하게 구성되어 있다.
- Python 클래스는 빠르게 만들 수 있어 편했지만, 너무 자유롭게 속성을 추가하면 코드가 헷갈릴 수 있다고 느꼈다.

## 9. 문자열 포맷팅

**강의 의도**

- `%`, `format()`, f-string을 비교하고 값을 보기 좋게 출력하는 방법을 익히는 것이다.
- 현재 Python에서는 f-string이 가장 읽기 쉬운 방법이라는 점을 확인했다.

**C·C++과 비교 및 느낀 점**

- C의 `printf`는 서식 지정자를 맞춰야 하고 실수하면 문제가 생길 수 있다.
- Python f-string은 변수와 식을 바로 넣을 수 있어 편했다. 출력이 간단해서 실행 결과를 확인하기 좋았다.

## 10. 모듈

**강의 의도**

- `import`로 이미 만들어진 기능을 가져와 사용하는 방법을 익히는 것이다.
- `math` 모듈과 좌표 회전 계산, pygame 예제를 통해 모듈의 활용을 확인했다.

**C·C++과 비교 및 느낀 점**

- C·C++은 보통 `#include`와 컴파일 과정을 거치지만 Python은 `import`로 비교적 간단히 기능을 가져올 수 있다.
- 필요한 기능을 빠르게 사용할 수 있는 점은 장점이지만, 외부 패키지는 설치와 버전 관리가 필요하다.

## 11. 리스트 컴프리헨션, map, lambda

**강의 의도**

- 반복문으로 만들던 리스트를 리스트 컴프리헨션으로 간단히 표현하는 방법을 익히는 것이다.
- `map`, `lambda`, `sorted`의 `key`를 사용해 변환과 정렬을 간단히 작성하는 방법을 확인했다.

**C·C++과 비교 및 느낀 점**

- C에서는 보통 반복문을 직접 작성해야 하고, C++은 알고리즘 라이브러리와 람다를 사용할 수 있다.
- Python은 짧게 쓸 수 있어 편했지만, 식이 너무 길어지면 일반 반복문보다 읽기 어려울 수 있다고 느꼈다.

## 전체 느낀 점

- Python은 문법이 간단해서 실행 결과를 빠르게 확인하기 좋았다.
- C와 C++은 자료형과 메모리를 더 명확하게 관리해야 하지만, 속도와 구조를 세밀하게 조절할 수 있다는 장점이 있다.
- Python도 편리한 문법만 사용하는 것보다 자료형의 특징과 실행 결과를 같이 확인하는 것이 중요하다고 생각했다.
